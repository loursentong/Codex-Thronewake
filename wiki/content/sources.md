## What this release covers

This first slice covers three Stormfang Clans units, their faction and five
prerequisite buildings. It is not the complete wiki. The existing wiki remains
available separately while the new reference grows.

## Evidence is attached to facts

Base values come from the certified catalogue dated **14 September 2026**. Later
developer statements and observations retain their own conditions. Page data files
preserve source identifiers, SHA-256 hashes and original field selectors.

Those hashes identify source bytes; they are not public links to private evidence.
Some originals cannot be inspected from this site. Never interpret an authorship
label, a passing build or a source-backed statistic as validation of every possible
gameplay conclusion. Unknown values are not silently replaced by zero.

The source-linked JSON on each page is intended for traceability and future reuse.
It is not an authenticated game API and includes no live account state.
