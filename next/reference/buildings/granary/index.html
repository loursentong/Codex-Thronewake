Current qualifications

Developer statement

Random Granary targeting

Random targeting can select the lower-level Granary; the highest-level choice is not guaranteed.

Wynfir explicitly answers Miles about two Granaries of different levels,18September2026, displayed17:01.

Limits: Developer-confirmed for the stated Granary scenario. No equal-level tie-break, probability distribution or generalization to every duplicate building type inferred.

Explicit Granary targeting

If Granary is explicitly selected, catapults target the highest-level Granary.
